## 6. 이날 배운 것 (RULES.txt 오답노트에 추가)

**오답노트 4 — 백엔드 API 만 만들고 프론트 연결을 빠뜨림**
서버 API 를 추가하면 그 자리에서 호출하는 쪽까지 연결하고 실제 요청을 태워 확인한 뒤에
완료로 볼 것. 프론트에 "API 가 없어서 막아둠" 자리표시자를 남겼다면 API 를 만들 때 같이 지운다.

**오답노트 5 — 프론트만 배포돼 기존 버튼이 사라짐**
이 레포는 **프론트 자동배포 / 백엔드 수동배포**라 배포 시차가 항상 있다.
프론트를 새 응답 필드에 의존시킬 때는 **그 필드가 없을 때의 동작을 반드시 정하고 폴백을 둘 것.**
`undefined` 가 곧 '숨김' 이 되면 안 된다. **배포 순서는 백엔드 먼저, 프론트 나중.**
