## 3. 지금 배포된 모델은 거의 찍기 수준입니다

**목적: 왜 굳이 바꿔야 하는지 숫자로 보여드리기 위해서입니다.**

사람이 직접 라벨을 단 기사 **116건**을 두 모델에 똑같이 풀렸습니다.

| | **지금 배포된 모델** | **새 모델** |
|---|---:|---:|
| 정확도 | **29.3%** (34/116) | **68.1%** (79/116) |
| 4지선다 찍기 | 25% | 25% |

**29.3% 는 눈 감고 찍는 것(25%)보다 겨우 나은 수준입니다.**

### 왜 이렇게 낮은가 — 거의 다 '진보'라고 답합니다

| 실제 정답 | 진보라고 답함 | 중립 | 보수 | 판단불가 |
|---|---:|---:|---:|---:|
| 진보 (32건) | 24 | 2 | 6 | 0 |
| 중립 (26건) | **19** | 2 | 5 | 0 |
| 보수 (32건) | **23** | 1 | 8 | 0 |
| 판단불가 (26건) | **21** | 2 | 3 | 0 |

- **116건 중 87건(75%)을 '진보'라고 답합니다.**
- **'판단불가'는 단 한 번도 답하지 않습니다.** 라벨이 네 개인데 사실상 한 개만 씁니다.
- 진보는 잘 맞히는 것처럼 보이지만(24/32), 다 진보라고 찍어서 그런 겁니다.

**즉 지금 서비스는 정치 기사 대부분에 '진보' 딱지를 붙이고 있습니다.**

### 새 모델은 네 라벨을 고르게 씁니다

| 라벨 | 정답 건수 | 새 모델이 답한 횟수 | 맞힌 수 |
|---|---:|---:|---:|
| 진보 | 32 | 28 | 21 |
| 중립 | 26 | 33 | 17 |
| 보수 | 32 | 20 | 15 |
| 판단불가 | 26 | 35 | 26 |

답한 횟수가 실제 건수와 비슷합니다. **한쪽으로 쏠리지 않는다는 뜻입니다.**

## 5. (P0) 왜 코드를 안 고쳐도 되나

**목적: "정말 그냥 갈아 끼우면 되나?" 라는 의심을 없애기 위해서입니다.**

새 모델과 기존 모델이 **완전히 같은 규격**이라서 그렇습니다.

| 확인 항목 | 기존 모델 | 새 모델 | |
|---|---|---|---|
| 모델 구조 | `BertForSequenceClassification` | 같음 | ✅ |
| 바탕 모델 | `klue/bert-base` | 같음 | ✅ |
| 어휘 사전 크기 | 32,000 | 같음 | ✅ |
| 라벨 순서 | 진보·중립·보수·판단불가 | **같음** | ✅ |
| 읽는 글자 수 | 512 | **512** (`main.py` 의 `MAX_LENGTH` 와 일치) | ✅ |
| 파일 구성 | config/safetensors/tokenizer | 같음 | ✅ |

**라벨 순서가 같다는 게 가장 중요합니다.** 순서가 다르면 서버가 '진보'를 '보수'로
바꿔 읽어도 에러가 안 나고 **조용히 틀린 답**을 냅니다. 확인해 두었습니다.

## 6. (P0) 바꾼 뒤 확인하는 법

**목적: 교체가 제대로 됐는지 5분 안에 확인하기 위해서입니다.**

### 6-1. 서버가 뜨는지

```bash

```

### 6-2. 판단불가를 실제로 답하는지 ← 가장 중요

**기존 모델은 '판단불가'를 한 번도 답하지 않았습니다.** 이게 나오면 교체 성공입니다.

```bash
curl -X POST http://localhost:8000/predict \
  -H 'Content-Type: application/json' \
  -d '{"title":"2027년도 예산안 국무회의 의결…총지출 821조",
       "body":"정부가 2027년도 예산안을 의결했다. 총지출은 821조원으로 전년 대비 늘었다."}'
```

## 7. (P1) 이 모델이 못 하는 것 — 알고 쓰셔야 합니다

**목적: 과신하지 않도록, 어디서 틀리는지 미리 알려드리기 위해서입니다.**

정확도 68% 는 **10건 중 3건은 틀린다**는 뜻입니다. 특히 다음이 약합니다.

| 라벨 | 얼마나 잡나 | 어떤 상태인가 |
|---|---|---|
| 판단불가 | 26/26 (100%) | 가장 잘합니다 |
| 진보 | 21/32 (66%) | 괜찮습니다 |
| 중립 | 17/26 (65%) | 다른 라벨을 중립으로 흘리는 경향이 있습니다 |
| **보수** | **15/32 (47%)** | **가장 약합니다. 절반을 놓칩니다** |

**보수 기사를 놓치는 것이 현재 가장 큰 약점입니다.**
다만 보수라고 답했을 때 맞을 확률은 75% 라, **틀리게 보수라고 하는 게 아니라
보수인데 조심스러워서 다른 답을 하는 쪽**입니다.

### 서비스에 반영할 때 권장

- **확신도(`확신도` 필드)를 함께 쓰세요.** 낮으면 "분류 보류"로 처리하는 편이 낫습니다.
- 정치성향 표시를 **단정적으로 하지 말고** "추정" 정도로 표현하는 것을 권합니다.

## 8. (P1) 이 모델이 무엇이고 어떻게 만들어졌나

**목적: 나중에 다시 학습시켜야 할 때 무엇을 건드려야 하는지 알기 위해서입니다.**

| 항목 | 내용 |
|---|---|
| 바탕 모델 | `klue/bert-base` (한국어로 사전학습된 공개 모델) |
| 학습 데이터 | 네이버 뉴스에서 모은 정치 기사 **17,696건** |
| 라벨을 누가 달았나 | Claude 가 기사를 직접 읽고 판정 (유료 API 미사용) |
| 채점 기준 | 사람이 직접 라벨을 단 **116건** — 학습에는 절대 넣지 않음 |
| 학습 장비 | MacBook Air M4 (GPU/MPS), **3시간 25분** |
| 학습 설정 | 학습률 4e-5 · 512자 · 배치 8 · 3회독 |

**콜랩 모델을 이어받은 게 아니라 공개 모델에서 새로 학습했습니다.**
기존 모델의 '진보 쏠림'을 물려받지 않기 위해서입니다.

### 라벨 기준 (판정 순서)

1. 제목·본문에 **가치판단적 표현**이 있으면 → 그 어조가 가리키는 진영
2. 평가어 없는 **순수 발언 전달**이면 → 중립
3. 국내 진영 대립이 기사의 축이 **아니면** → 판단불가
   (국제·외교, 지역 개발·예산, 행정·수사 절차, 역사·문화)

**주의: 기사의 입장 ≠ 기사에 나오는 정치인의 입장.**
"민주당 의원이 법안 발의"는 진보 기사라는 뜻이 아닙니다. 어조와 프레이밍을 봅니다.
