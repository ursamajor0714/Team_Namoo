  → start.spring.io 접속
  → 설정값: Language=Java, Type=Gradle-Groovy, Java=17, Spring Boot=3.3.x
  → Dependencies: Spring Web, Spring Data JPA, H2 Database, Lombok, Validation
  → 다운로드 후 IntelliJ에서 Open

[0-4] Node.js 설치 | 담당: FE | 30분
  → nodejs.org 에서 LTS 버전(22.x) 설치
  → 터미널에서 node -v, npm -v 로 확인

[0-5] VS Code 설치 & 확장 | 담당: FE | 30분
  → VS Code 설치
  → 확장 설치: ES7+ React Snippets, Prettier, ESLint, Auto Rename Tag

[0-6] React 프로젝트 생성 | 담당: FE | 30분
  → 터미널에서 실행:
     npx -y create-vite@latest peach-place-frontend -- --template react
  → cd peach-place-frontend && npm install

[0-7] Git 저장소 초기화 | 담당: ALL | 30분
  → git init
  → .gitignore 설정 (node_modules, build, .env 등)
  → 첫 커밋

 Phase 1: 백엔드 기본 구축 (Day 3~5)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[1-1] application.yml 설정 | 1시간
  → src/main/resources/application.yml 에 아래 내용 작성:
     server.port: 8080
     spring.datasource.url: jdbc:h2:mem:peachplace
     spring.h2.console.enabled: true
     spring.jpa.hibernate.ddl-auto: create-drop
     google.maps.api-key: ${GOOGLE_API_KEY}
     openai.api-key: ${OPENAI_API_KEY}
  ★ 주의: API 키는 절대 코드에 직접 쓰지 말고 환경변수로!

[1-2] CORS 설정 (WebConfig.java) | 30분
  → config 패키지에 WebConfig.java 생성
  → @Configuration + WebMvcConfigurer 구현
  → addCorsMappings 에서:
     allowedOrigins("http://localhost:5173")
     allowedMethods("GET","POST","PUT","DELETE")
  ★ 이게 없으면 프론트에서 API 호출 시 차단됨!

[1-3] Google Maps Config | 30분
  → GoogleMapsConfig.java 에서 GeoApiContext Bean 생성
  → @Value("${google.maps.api-key}") 로 키 주입
  → new GeoApiContext.Builder().apiKey(apiKey).build() 반환

[1-4] DTO 클래스 작성 | 2시간
  → dto 패키지에 Request/Response 클래스 작성
  → 각 클래스에 @Getter, @Setter, @NoArgsConstructor, @AllArgsConstructor 붙이기
  → PlaceSearchResponse 필드:
     placeId, name, address, lat, lng, rating, category, photoUrl, openNow
  → 총 6개 DTO 작성

[1-5] Favorite 엔티티 | 1시간
  → entity/Favorite.java
  → @Entity, @Table(name="favorites")
  → @Id @GeneratedValue(strategy=GenerationType.IDENTITY) Long id
  → 나머지 필드 선언
  → @CreatedDate LocalDateTime createdAt

[1-6] PlaceCache 엔티티 | 30분
  → entity/PlaceCache.java 같은 패턴
  → data 필드는 @Column(columnDefinition="TEXT")

[1-7] Repository 인터페이스 | 30분
  → FavoriteRepository.java: extends JpaRepository<Favorite, Long>
  → PlaceCacheRepository.java: extends JpaRepository<PlaceCache, Long>
     Optional<PlaceCache> findByPlaceId(String placeId) 추가

[1-8] PlaceService 구현 | 4시간 ★핵심★
  → service/PlaceService.java, @Service
  → Google Maps Services 라이브러리 사용
  → searchPlaces(query, lat, lng, radius)
     → PlacesSearchResponse.results → DTO 매핑
  → getPlaceDetail(placeId)
     → PlaceDetails → DTO 매핑
  → 캐시 로직: 조회 시 DB 캐시 확인 → 없으면 API 호출 → 캐시 저장

[1-9] GptService 구현 | 3시간
  → service/GptService.java
  → OpenAI Java SDK 사용
  → 시스템 프롬프트:
     "사용자의 요청에 맞는 장소 종류를 추천해줘.
      JSON 배열로 [{type, keyword}] 형태로 응답해."
  → 사용자 프롬프트 전달 → GPT 응답 파싱 → PlaceService.searchPlaces() 호출
  → 결과 반환

[1-10] FavoriteService 구현 | 1시간
  → service/FavoriteService.java
  → CRUD 로직: getAll(), add(FavoriteDto), delete(Long id)

[1-11] PlaceController | 2시간
  → controller/PlaceController.java
  → @RestController @RequestMapping("/api/places")
  → @GetMapping("/search"), @GetMapping("/nearby"), @GetMapping("/{placeId}")
  → 각각 PlaceService 호출 후 ResponseEntity 반환

[1-12] GptController | 1시간
  → @PostMapping("/api/places/gpt-recommend")
  → RequestBody로 GptRecommendRequest 받기

[1-13] FavoriteController | 1시간
  → @RestController @RequestMapping("/api/favorites")
  → GET/POST/DELETE 매핑

[1-14] API 테스트 | 2시간
  → Postman 또는 IntelliJ HTTP Client로 모든 엔드포인트 테스트
  → 200 OK 확인
  → 에러 시 로그 확인 후 디버깅

━━━ 6-1. Spring Boot — PlaceController.java ━━━

@RestController
@RequestMapping("/api/places")
@RequiredArgsConstructor
public class PlaceController {

    private final PlaceService placeService;

    @GetMapping("/search")
    public ResponseEntity<List<PlaceSearchResponse>> search(
            @RequestParam String query,
            @RequestParam(defaultValue = "37.5665") double lat,
            @RequestParam(defaultValue = "126.9780") double lng,
            @RequestParam(defaultValue = "5000") int radius) {

        List<PlaceSearchResponse> results =
            placeService.searchPlaces(query, lat, lng, radius);
        return ResponseEntity.ok(results);
    }

    @GetMapping("/{placeId}")
    public ResponseEntity<PlaceDetailResponse> detail(
            @PathVariable String placeId) {
        PlaceDetailResponse detail = placeService.getPlaceDetail(placeId);
        return ResponseEntity.ok(detail);
    }
}


━━━ 6-2. React — MapView.jsx ━━━

import { APIProvider, Map, AdvancedMarker }
  from '@vis.gl/react-google-maps';
import { usePlaceStore } from '../../store/usePlaceStore';
import { useMapStore } from '../../store/useMapStore';

const MAPS_API_KEY = import.meta.env.VITE_GOOGLE_MAPS_KEY;

export default function MapView() {
  const { places, setSelectedPlace } = usePlaceStore();
  const { center, zoom, setCenter, setZoom } = useMapStore();

  return (
    <APIProvider apiKey={MAPS_API_KEY}>
      <Map
        center={center}
        zoom={zoom}
        onCameraChanged={(ev) => {
          setCenter(ev.detail.center);
          setZoom(ev.detail.zoom);
        }}
        mapId="PEACH_PLACE_MAP"
        disableDefaultUI
      >
        {places.map((place) => (
          <AdvancedMarker
            key={place.placeId}
            position={{ lat: place.lat, lng: place.lng }}
            onClick={() => setSelectedPlace(place)}
          />
        ))}
      </Map>
    </APIProvider>
  );
}

[2] 원리

- 가게 테이블에 lat, lng 컬럼을 둔다.
- 그 좌표만 카카오맵 SDK에 넘기면, SDK가 현재 지도 중심/줌 레벨
  기준으로 화면 어디에 찍을지 알아서 계산한다.
- 지도를 드래그하거나 확대/축소해도 마커가 알아서 제자리를 지킨다.
- CSS로 top/left를 박아두면 지도가 조금만 움직여도 다 어긋나기
  때문에, 실제로 움직이는 지도에서는 쓰지 않는 방식이다.

[3] 가게 심을 때 좌표는 어디서 구하나

- 주소만 입력하면 카카오 Geocoder가 좌표로 변환해준다.
- 가게 등록 시 한 번만 변환하면 되고, 변환된 좌표를 DB에 저장해둔다.
- 그 다음부터는 저장된 lat/lng을 그대로 쓰면 된다.
  (렌더링할 때마다 다시 변환할 필요 없음)

[4] 코드 예시

1) 가게 심을 때 - 주소 -> 좌표 (한 번만)

    const geocoder = new kakao.maps.services.Geocoder();
    geocoder.addressSearch(store.address, (result, status) => {
      if (status === kakao.maps.services.Status.OK) {
        // result[0].y = 위도, result[0].x = 경도 -> DB에 저장
      }
    });

2) 지도에 뿌릴 때 - DB 좌표 -> 마커

    stores.forEach(store => {
      new kakao.maps.Marker({
        map,
        position: new kakao.maps.LatLng(store.lat, store.lng)
      });
    });

[5] 참고 사항

- Geocoder를 쓰려면 SDK 로드할 때 &libraries=services 파라미터를
  꼭 붙여야 한다. 안 붙이면 kakao.maps.services가 undefined로 뜬다.

- 이 Geocoder(주소->좌표 변환)는 이전에 빼기로 한 "키워드 장소 검색"과는
  다른 기능이라 그 결정과 겹치지 않는다.

- 이 변환을 프론트에서 안 하고, 스프링부트 쪽에서 카카오 REST API
  (dapi.kakao.com/v2/local/search/address.json)로 미리 돌려서 DB에
  좌표까지 채워놓는 방법도 있다. 가게 심는 스크립트/배치를 한 번
  돌리고 끝나는 구조라 이 쪽이 더 깔끔할 수도 있다.
